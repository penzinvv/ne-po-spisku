# Не по списку

**«Не по списку»** — браузерная игра о работе в банкетном зале. Играй прямо на сайте: [banquetgang.netlify.app](https://banquetgang.netlify.app/). Установка не требуется.

## Управление

- **WASD** или **стрелки** — перемещение персонажа.
- **E** — взаимодействие: взять или доставить поднос, когда это предусмотрено заданием.
- **На телефоне** — используй экранные стрелки и кнопку действия.
- **В мини-игре с посудой** — перемещение влево/вправо или клавиши **A/D**.

## Что есть в игре

- Задания, которые открываются последовательно по мере прохождения.
- Диалоги с персонажами и игровые ситуации, связанные с работой на банкете.
- Перемещение по игровым помещениям и взаимодействие с предметами.
- Столкновения с персонажами могут повлиять на прохождение задания.
- История прохождения доступна из профиля игрока.
- Таблица **«ТОП-10 лучших показателей»** показывает лучшие результаты.

## Запуск

Открой [игру в браузере](https://banquetgang.netlify.app/). На компьютере можно пользоваться клавиатурой, на телефоне — экранными элементами управления.
